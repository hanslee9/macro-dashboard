# macro-dashboard 스타일 시각화 프롬프트 템플릿

> 용도: Claude.ai 프로젝트의 "프로젝트 지식"에 이 문서를 등록해두면,
> macro-dashboard 앱과 동일한 형식·규칙으로 그래프를 그려달라고 요청할 수 있습니다.
> 아래 [표준 지시문]을 그대로(또는 괄호 부분만 바꿔서) 복사해 붙여넣으면 됩니다.

---

## 1. 이 문서를 쓰는 이유

macro-dashboard 앱은 단순히 "그래프를 그린다"가 아니라, 아래와 같은 **일관된 규칙**을 따릅니다.

- 시작점을 100으로 맞추는 정규화 방식
- 로그스케일 적용 시 0 이하 값 자동 제외
- 정책금리류는 계단식(step) 렌더링
- 장기추세선 대비 이격률(%) 계산 방식(로그선형회귀)
- 지표명·단위 표기 규칙

Claude.ai 채팅에서 그냥 "코스피 10년 그래프 그려줘"라고만 하면 이런 세부 규칙 없이
임의의 형태로 그려질 수 있습니다. 이 문서를 프로젝트 지식에 등록해두면,
**앱과 똑같은 논리로 그려달라**고 한 번에 요청할 수 있습니다.

## 3. 정확한 데이터 소스 확인 절차 (가장 중요)

**그래프를 그리기 전에, 반드시 `각종_거시경제지표_해설_최종판.xlsx`(또는 최신 버전) 파일에서
해당 지표의 정확한 코드/출처를 먼저 확인해줘.**

```
[지표명] 그래프를 그려줘.
먼저 프로젝트에 등록된 "각종_거시경제지표_해설" 엑셀 파일에서 이 지표의
"코드/소스코드"와 "데이터 출처" 열을 확인하고, 그 정확한 코드(FRED 시리즈ID,
Yahoo Finance 티커 등)로 데이터를 가져와줘. 엑셀에 없는 지표라면 그렇다고
먼저 알려주고, 어떤 소스를 쓸지 물어봐줘.
```

**이렇게 해야 하는 이유**

- FRED·Yahoo Finance는 같은 개념의 지표라도 **여러 개의 유사한 코드/티커**가 존재함
  (예: 미국 기준금리만 해도 FEDFUNDS, DFEDTAR, DFEDTARU 등 여러 시리즈가 있고
  성격이 각각 다름)
- 엑셀 없이 "미국 기준금리 그래프 그려줘"라고만 하면, Claude가 **매번 다른 코드를
  추측**해서 가져올 수 있어 결과가 대시보드와 미묘하게 달라질 위험이 있음
- 엑셀 파일의 "코드/소스코드" 열을 그대로 지정해주면, **대시보드에서 실제로 쓰는
  것과 정확히 같은 원본 데이터**로 그래프가 그려짐
- ⚠ 표시(현재 미작동)가 있는 지표는 Claude에게도 "이 지표는 대시보드에서도 현재
  데이터를 못 가져오는 상태다"라고 미리 알려주는 효과도 있음(같은 함정 반복 방지)

### ⚠ 중요한 환경적 한계 (실제 테스트로 확인됨)

**엑셀에 정확한 코드가 있어도, 일반 Claude.ai 채팅은 그 코드로 대량의 시계열
데이터(예: 10년치 일별 종가 2,500개)를 자동으로 못 가져올 수 있습니다.**

- macro-dashboard 앱은 서버에서 `yfinance` 같은 파이썬 라이브러리로 데이터 API를
  **직접 호출**하지만, 일반 Claude.ai 채팅은 웹페이지를 "열어보는" 방식이라
  대부분의 금융 데이터 사이트(Yahoo Finance, 네이버증권, Stooq 등)의 봇 차단·
  페이지네이션 제약에 그대로 걸립니다
- Investing.com 등 일부 사이트는 접속은 되지만 **최근 1개월치만** 노출되는 등
  날짜 파라미터가 무시되는 경우가 많습니다
- 즉 **"엑셀 = 어떤 코드를 써야 하는지 알려주는 지도"**일 뿐, **"그 코드로 실제
  대량 데이터를 가져올 능력"까지 보장하지는 않습니다**

**가장 확실한 대안 — 데이터를 직접 다운로드해서 함께 첨부**

이 프로젝트에서 한국 기준금리·M2를 해결했던 방식과 동일합니다.

```
1. Yahoo Finance(또는 investing.com, 네이버증권 등)에서 원하는 지표의
   과거 데이터를 직접 다운로드(CSV/엑셀)
   - Yahoo Finance: 해당 종목 페이지 → "Historical Data" 탭 →
     기간 설정 → "Download" 버튼
2. 이 CSV/엑셀 파일을 대화창에 함께 첨부
3. "첨부한 데이터로 [표준 지시문에 따라] 그래프를 그려줘"라고 요청
```

이렇게 하면 Claude가 **이미 확보된 데이터를 그대로 시각화**하기만 하면 되므로,
접속 차단·페이지네이션 문제와 무관하게 **100% 안정적으로 작동**합니다.

**차선책 — 월간/분기 단위로 요청 범위 축소**

데이터를 직접 받기 번거로우시면, 요청 범위를 줄여서 검색만으로도 가능한 수준으로
낮추는 방법도 있습니다.

```
[지표명]의 최근 [기간]년치를 "일간" 대신 "월간" 데이터로 그려줘.
데이터 포인트 수가 훨씬 적어(예: 10년 기준 일간 2,500개 vs 월간 120개),
검색으로 찾은 요약 자료로도 그릴 수 있는 가능성이 높아짐. 다만 이 경우도
정확한 전 기간 데이터를 못 찾으면 "일부 구간만 확보했다"고 명시해줘.
```

**차선책 2 — FRED의 CSV 다운로드 엔드포인트 활용 (Yahoo/네이버가 막힐 때 유용)**

FRED는 일반 HTML 페이지라 봇 차단이 거의 없고, 특히 아래 형태의 URL은
**순수 데이터 파일(CSV)**이라 페이지네이션·JS 렌더링 문제 없이 전체 기간을
한 번에 가져올 수 있는 경우가 많습니다.

```
https://fred.stlouisfed.org/graph/fredgraph.csv?id=[FRED 시리즈ID]
```

- FRED는 미국 지표 외에 **OECD가 집계한 각국 데이터(한국 포함)도 미러링**하고
  있어, 원본 사이트(Yahoo Finance 등)가 막혀도 FRED 경유로 얻어지는 경우가 있음
- 다만 **원래 지표와 정확히 같은 값이 아닐 수 있음**에 주의
  (예: 코스피 "포인트" 값이 아니라 OECD가 표준화한 "주가지수(특정연도=100 기준)")
  → 이 경우 "이건 원래 지표의 근사/대체 지수"라고 반드시 명시하도록 요청할 것

```
[지표명]을 Yahoo Finance/네이버 등에서 못 가져오면, FRED에 이 지표를 미러링하는
비슷한 시리즈가 있는지 검색해서 fredgraph.csv 엔드포인트로 가져와줘.
단, 원본과 정확히 같은 수치가 아닐 수 있으니 그 경우 그래프에 "근사 대체 지수"라고
명시해줘.
```

## 4. 표준 지시문 (그대로 복사해서 쓰세요)

### 2-1. 단일 지표 그래프

```
[지표명]의 최근 [기간]년치 그래프를 그려줘.
- 일간 종가 기준, 선 그래프
- Y축은 원본 값 그대로(별도 요청 없으면 정규화·로그스케일 적용하지 않음)
- 최근 시점 값을 그래프 우측에 라벨로 표시
- 데이터 출처를 그래프 하단에 한 줄로 명시(예: "출처: Yahoo Finance" 또는 "출처: FRED")
```

### 2-2. 두 지표 비교 그래프 (단위가 같을 때)

```
[지표A]와 [지표B]를 같은 그래프에 겹쳐서 그려줘.
- 각각 다른 색으로 구분, 범례 표시
- 단위가 같으면 단일 Y축 사용
- 데이터 출처를 각 지표별로 하단에 명시
```

### 2-3. 두 지표 비교 그래프 (단위가 다를 때 — 정규화)

```
[지표A]와 [지표B]를 비교하는 그래프를 그려줘.
- 단위가 서로 달라서 직접 비교가 어려우니, "시작점 기준 정규화"를 적용해줘
  (계산법: 각 시리즈를 자기 시작값으로 나누고 100을 곱함 → 두 시리즈 모두 시작점=100에서 출발)
- 이렇게 하면 절대값이 아니라 "각자의 시작 대비 몇 % 변했는지"를 비교하는 그래프가 됨
- Y축 라벨에 "정규화 지수 (시작점=100)"라고 표기
```

### 2-4. 로그스케일 그래프

```
[지표명]을 로그스케일 Y축으로 그려줘.
- 장기간(예: 10년 이상)에 걸쳐 수십~수백 배 변한 지표를 볼 때 사용
- 주의: 0 이하 값이 하나라도 있으면 로그스케일을 적용할 수 없으니,
  그런 경우 "0 이하 값이 포함되어 로그스케일을 적용할 수 없습니다"라고 알려주고
  일반(선형) 스케일로 대신 그려줘
```

### 2-5. 정책금리류(계단식) 그래프

```
[한국 기준금리 / 미국 기준금리]를 그려줘.
- 이 지표는 결정된 시점에만 값이 바뀌고 그 사이는 완전히 동일하게 유지되는 값이니,
  일반적인 직선 보간(두 점을 사선으로 잇는 방식) 대신
  "계단식(step function)"으로 그려줘 — 변경 시점에만 수직으로 오르내리고,
  그 사이는 완전히 수평으로 유지
- (참고: plotly라면 line_shape='hv' 옵션에 해당)
```

### 2-6. 장기추세선 대비 이격률(%) 그래프

```
[지표명]의 "장기추세선 대비 이격률(%)"을 계산해서 그래프로 그려줘.
계산법:
1. 전체 기간 데이터에 로그값(자연로그)을 취함
2. 그 로그값에 대해 시간(x축, 그냥 순번 0,1,2...)을 독립변수로 한 선형회귀(최소제곱법)를 적용
3. 회귀식으로 각 시점의 "추세값"을 구하고, 다시 지수함수(exp)를 취해 원래 스케일로 복원
4. 이격률(%) = (실제값 ÷ 추세값 - 1) × 100
5. 결과는 양수면 "추세선 위(고평가 방향)", 음수면 "추세선 아래(저평가 방향)"로 해석
※ 값이 0 이하인 지표에는 로그를 취할 수 없어 이 방식을 적용할 수 없음을 먼저 확인해줘.
```

### 2-7. 지수간 상관관계 분석

```
[지표A]와 [지표B]의 상관관계를 분석해줘.
- 월말 기준으로 리샘플링한 뒤 피어슨 상관계수 계산
- 동시(0개월), 3개월, 6개월, 12개월 시차(lag)별로 각각 계산
  (lag>0은 "[지표A]가 [지표B]를 그만큼 선행한다"고 가정했을 때의 상관계수)
- 표본이 24개월 미만이면 "가용 데이터 구간이 짧아 신뢰성이 낮을 수 있다"고 명시
- 상관계수 절댓값 기준 해석: 0.7 이상=강한, 0.4~0.7=보통 수준, 0.2~0.4=약한, 0.2 미만=상호 관련성 낮음
- 상관계수는 인과관계를 의미하지 않는다는 점을 항상 명시
```

### 2-8. 전월대비/전년동월대비 변화율 그래프

```
[지표명]을 "전월대비(%)" 변화율로 바꿔서 그려줘.
- 가격(추세형) 지표를 GDP성장률처럼 이미 변화율인 지표와 비교할 때 특히 유용
  (레벨끼리 비교하면 장기추세가 섞여 허위상관이 생기기 쉬움)
- 계산법: 월말 기준으로 리샘플링 후, (이번달 값 ÷ 지난달 값 - 1) × 100
```

## 5. 지표명·단위 표기 규칙 (일관성 유지용)

| 항목 | 규칙 |
|---|---|
| 한국 관련 지표 | 한글 지표명 그대로 사용 (예: "코스피지수", "한국 기준금리") — 영문 약어(KOSPI, KRX 등)는 밸류에이션 배수류에만 사용 |
| 미국 관련 지표 | "미국 ○○" 형태 (예: "미국 CPI", "미국 실업률") |
| 파생지표 이름 | 원본지표명 + "(추세이격률, %)" 또는 "(월간수익률, %)" 형태로 명시 |
| 데이터 출처 표기 | 항상 그래프 하단 또는 텍스트에 한 줄로 명시 (예: "출처: FRED", "출처: Yahoo Finance", "출처: multpl.com") |
| 결측/추정 데이터 | 반드시 "⚠ 이 구간은 추정치/근사치입니다"라고 명시, 조용히 넘어가지 않기 |

## 6. 데이터 신뢰성 관련 유의사항 (요청 시 함께 안내)

이 macro-dashboard 개발 과정에서 실제로 겪었던 함정들입니다. Claude.ai에서 유사한
분석을 요청할 때도 아래 사항을 염두에 두고 결과를 검증하는 것이 좋습니다.

- **PER·CAPE 등 밸류에이션 배수**: 계산에 쓰이는 두 시리즈(예: 배당수익률과 PER)의
  날짜 표기 방식이 다르면(월초 vs 월말) 단순 결합 시 데이터가 하나도 안 겹쳐
  결과가 텅 빌 수 있음 → 월말 등 공통 기준으로 리샘플링 후 결합 권장
- **정규화+로그스케일 동시 적용**: 추세이격률·금리차처럼 음수가 가능한 지표는
  정규화해도 음수가 남아있어 로그스케일과 함께 쓰면 그래프가 왜곡됨 → 사전 확인 필요
- **한국 공공기관 데이터(한국은행 ECOS, 통계청 KOSIS, 한국거래소 KRX)**: 무료 API가
  있어도 자동화 파이프라인(서버→서버 요청)에서 접속이 불안정하거나 차단될 수 있음.
  Claude.ai 채팅에서 직접 요청하는 경우(브라우저 기반 웹서치)에는 이런 제약이
  적을 수 있으나, 정확한 수치는 항상 원본 출처와 대조 확인 권장
- **상관계수 해석**: 절대적 크기만으로 "관계가 강하다/약하다"고 단정하지 말고,
  위기 국면(2008, 2020 등) 특정 구간이 전체 상관계수를 왜곡시키고 있지 않은지
  구간을 나눠서도 확인하는 것을 권장

macro-dashboard와 정확히 동일한 원본 데이터·동일한 논리로 그래프를 그립니다.
