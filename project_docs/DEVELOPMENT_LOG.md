## 1. 프로젝트 개요

미국·한국 거시경제지표, 금리, 지수·주가, 신용·부채, 원자재, 밸류에이션 배수 등을
한 화면에서 선택·비교하고, 지표 간 상관관계를 통계적으로 분석하는 Streamlit 대시보드.

- **총 지표 수**: 80개 (9개 카테고리)
- **파일 구성**: `app.py`(UI/화면), `data_sources.py`(데이터 수집), `indicator_descriptions.py`(지표 설명 DB), `correlation_narratives.py`(고정 해설 DB)
- **실행 환경**: 평소(대부분)에는 로컬 PC에서 실행, 외부(회사 등)에서는 Streamlit
  Community Cloud 배포 URL 사용. 코드는 GitHub에 단일 버전만 유지하며, 환경별로
  자동 분기되도록 설계(4-1항목 참고).

## 4. 핵심 기능

- **그래프**: 최대 4개 지표 동시 비교, 정규화(시작점=100), 로그스케일, 계단식 렌더링(`line_shape='hv'`, 정책금리류)
- **지수간 상관관계**: 동시(0)/3/6/12개월 시차 상관계수, 회귀 기반 동적 관찰 문장 자동 생성
- **📚 학계·전문가 참고 시각**: `correlation_narratives.py`에 사전 등록된 지표 조합에 한해 고정 해설 표시(현재 31개 조합 등록)
- **📖 지표 설명**: 선택한 지표 개수와 무관하게 항상 표시, `indicator_descriptions.py` 기반(80개 전체 등록)
- **추세이격률 회귀 통계**: 로그선형회귀 기반 장기추세 대비 이격도, 평균회귀 소요기간 요약
- **커스텀 지표 추가**: 화면에서 FRED 코드/yfinance 티커를 즉석 입력해 세션 한정 추가 가능

### 4-1. 로컬/클라우드 자동 분기 (2026-08-19 신규)

KOSPI PER/PBR/배당수익률 3개 지표는 다음과 같이 **하나의 코드가 실행 환경에 따라
자동으로 다르게 동작**하도록 설계되어 있음(파일을 환경별로 나누지 않음):

1. KOSIS API 실제 호출을 짧은 타임아웃(8초)으로 시도
2. 성공하면 실데이터 반환 → **로컬 PC(국내 IP)에서는 대부분 이 경로**
3. 실패(타임아웃 등)하면 기존과 동일한 결측 처리 메시지로 자동 대체 →
   **Streamlit Cloud(해외 클라우드 IP)에서는 이 경로**

이 설계로 로컬 실행 시에는 실데이터를, 외부(클라우드) 접속 시에는 안전하게
결측 메시지를 보여주는 두 가지 요구사항을 코드 하나로 동시에 만족시킴.
로컬 실행 절차는 `LOCAL_RUN_GUIDE.md` 참고.

## 6. 한국 공공기관 API 관련 — 중요 히스토리

이번 개발에서 가장 많은 시간이 소요된 부분. **3개 경로를 순차 시도했으나 전부 Streamlit Cloud에서 네트워크 차단** 확인:

1. **ECOS(한국은행 경제통계시스템)** — API 키 발급, 통계표코드까지 확인했으나 `ConnectTimeoutError`로 접속 자체가 안 됨. 브라우저로는 정상 접속되는 것으로 봐서 Streamlit Cloud의 서버 IP(해외 클라우드)를 차단하는 것으로 추정.
2. **KOSIS(국가통계포털)** — 처음엔 응답을 받았으나(항목혼입 버그만 있었음), 이후 재시도 시 동일하게 `ConnectTimeoutError` 발생. 5개 지표(M2, KOSPI PER/PBR/배당수익률/시가총액) 전수 테스트로 확인.
3. **pykrx(한국거래소 KRX, 로그인 방식)** — `pkg_resources` 패키징 이슈(→ `setuptools` 버전 문제)까지 해결했으나, 최종적으로 "로그인 실패 가능성 포함, 조회결과 비어있음" — 이 역시 같은 도메인 차단 패턴으로 추정.

**최종 결론 및 대응 (기존 대응)**:
- 기준금리·M2: **코드에 값을 직접 하드코딩**하는 방식으로 전환(사용자가 매월/금통위 시점마다 값 갱신 필요)
- KOSPI PER/PBR/배당수익률/시가총액: 당초 **결측 처리 확정**("해당 데이터를 불러올 수 없습니다")

### 6-1. 로컬 PC 접속 재확인 및 3개 지표 복구 (2026-08-19 추가)

로컬 PC(Windows, 국내 IP)에서 별도 독립 테스트 스크립트로 ECOS/KOSIS 접속을
재확인한 결과, **로컬 환경에서는 두 API 모두 정상 접속 및 데이터 수신 확인됨**
(HTTP 200). 이는 위 1~2번 항목의 접속 차단이 "네트워크 자체의 문제"가 아니라
**Streamlit Cloud 서버(해외 클라우드 IP)에 한정된 차단**이었음을 뒷받침함.

이에 따라 `get_kospi_per()`, `get_kospi_pbr()`, `get_kospi_dividend_yield()`
3개 함수를 "무조건 실패"에서 "KOSIS 실제 호출 시도 → 실패 시에만 결측 처리"
방식으로 변경(4-1항목 참고). `get_kospi_market_cap()`은 정확한 tblId를
확정하지 못해 결측 처리를 유지함(7번 항목 참고).

### 갱신 방법 (참고)
- **기준금리**: `get_korea_base_rate()` 함수의 `history` 리스트 맨 끝에 `("YYYY-MM-DD", 값)` 한 줄 추가
- **M2**: `get_korea_m2()` 함수의 `history` 리스트 맨 끝에 `("YYYY-MM", 값)` 한 줄 추가 (매월, snapshot.bok.or.kr에서 최신값 확인)

## 7. 발견·수정된 주요 버그

| 버그 | 원인 | 수정 |
|---|---|---|
| 존재하지 않는 FRED 코드(가계부채 HHDNS, 경상수지 BOPBCA 등) | 코드 오탈자/폐기된 시리즈 | 유효한 대체 코드로 교체(CMDEBT, IEABC 등) |
| KOSPI PER이 500까지 튀는 현상 | KOSIS 응답에 여러 세부항목이 섞여 옴(항목혼입) | 원칙적 항목선택 로직(`_select_primary_item`) — 단, 2026-08-19에 이 로직 자체의 결함이 추가로 발견됨(아래 항목) |
| **(2026-08-19 신규) `_select_primary_item`이 잘못된 컬럼을 기준으로 항목을 선택** | KOSIS PER/PBR/배당수익률 표(tblId=S0032~S0034)의 실제 세부항목(KOSPI/KOSPI 200/제조업/대형주 등) 구분은 `ITM_ID`·`ITM_NM`이 아니라 **`C1_NM`** 컬럼에 있었음. 기존 코드는 `ITM_ID`/`ITM_NM`을 봤는데 이 컬럼은 표 전체에서 값이 1개뿐이라(예: "주가이익비율") 사실상 필터링이 안 되고 있었음 | `get_kosis_series()`에서 항목 선택 컬럼 우선순위를 `C1_NM` → `ITM_ID` → `ITM_NM` 순으로 변경. 또한 검색 키워드를 한글 `"코스피"`가 아니라 실제 값인 영문 **`"KOSPI"`**로 수정(한글로는 매칭되지 않아 결과적으로 무작위 항목이 채택되고 있었음) |
| 배당성향/ROE 데이터 로딩 실패(에러 메시지 없음) | multpl.com 페이지마다 날짜 표기(월초/월말)가 달라 결합 시 완전히 안 겹침 | 월말 기준 리샘플링 통일 |
| S&P500 `'>=' not supported between numpy.ndarray and Timestamp` | `@st.cache_data` 데코레이터 중복 적용으로 인덱스 타입 손상 | 중복 제거 + 비교 직전 명시적 재정규화 |
| S&P500 간헐적 로딩 실패 | PEG 계산이 별도로 Yahoo Finance에 중복 요청 | ^GSPC 전용 마스터 캐시로 통합, 항상 1회만 호출 |
| 실러PER(CAPE) 등 일부 지표 정규화+로그스케일 조합 시 그래프 왜곡 | 정규화 모드에서 0 이하 값 로그스케일 적용 시 안전성 체크 누락 | 원본 모드와 동일하게 0 이하 값 자동 감지·로그스케일 해제 |
| CBOE 풋/콜비율 2019년 10월 이후 데이터 없음 | 소스(CBOE) 자체가 해당 공개 CSV 갱신 중단 | 지표 완전 삭제(대체소스 없음 확인) |

## 8. 알려진 한계 / 주의사항

- **하이일드·투자등급 스프레드**: 제공기관(ICE Data Indices) 정책 변경으로 2026년 4월부터 FRED에서 최근 3년치만 제공
- **ISM 제조업 PMI**: 공식 유료소스 대신 DBnomics 무료 재배포 사용, 25~75 범위를 벗어나는 비정상값 자동 필터링
- **한국 기준금리**: 정책금리 원본이 아니라 하드코딩된 값(매 금통위마다 수동 갱신 필요). 로컬은 실시간 API 접속이 가능하나, 계단식 특성상 하드코딩 유지가 더 안정적이라 판단해 그대로 둠(변경하지 않음)
- **PEG비율**: 향후 이익성장률 전망치가 아닌 과거(trailing) EPS 성장률 기반 근사치
- **KOSPI PER/PBR/배당수익률**: ~~현재 데이터 소스 없음(결측 처리)~~ → **2026-08-19: 로컬 PC 실행 시 KOSIS 실시간 데이터로 정상 표시됨. Streamlit Cloud에서는 여전히 결측 처리(접속 차단, 정상 동작).**
- **KOSPI 시가총액**: 여전히 데이터 소스 미확정. tblId=DT_343_2010_S0026("업종별 시가총액")을 시도했으나 실제 공식 시가총액(2026년 6월 기준 약 7,215조원, 언론 보도 대조)과 약 8배 차이가 나 사용 보류. 정확한 tblId(코스피 전체 시가총액 단일 시계열)를 추후 KOSIS 사이트에서 직접 확인 후 재구현 필요.
